# Prisma schema + initial migration + seed

> Lane: DB. Owns `prisma/**`. This task is part of the Phase-1 **freeze** — after it lands,
> `prisma/schema.prisma` must not be edited by feature lanes (CLAUDE.md rule 17).

## Context
Persist the data model so every later lane can rely on a stable schema. Advances FR-6…FR-15 (all data).

**Required reading:** [`CLAUDE.md`](../../CLAUDE.md) · [`mvp-decisions.md`](../mvp-decisions.md) ·
[`architecture.md`](../architecture.md) §3 (data model) · [`task-breakdown.md`](../task-breakdown.md) #1.1.

## Goal & non-goals
- **Goal:** A migrated Postgres schema for Trainer, Group, Customer, InbodyEntry, Reaction + a seed.
- **Non-goals:** No metrics/numeric columns, no status enum, no comment-thread table (deferred).

## Files I own
- `prisma/schema.prisma`, `prisma/migrations/**`, `prisma/seed.ts`

## Approach
1. Datasource `postgresql` from `env("DATABASE_URL")`; generator `prisma-client-js`.
2. Models (see [`architecture.md`](../architecture.md) §3):
   - `Trainer { id, email @unique, passwordHash, name, slug @unique, createdAt, groups[], customers[] }`
   - `Group { id, trainerId, name, note?, createdAt }` — `trainer` relation, `customers[]`.
   - `Customer { id, trainerId, groupId, name, nameNormalized, passwordHash, createdAt }`
     - `@@unique([trainerId, nameNormalized])`; relations to Trainer, Group, `entries[]`.
   - `InbodyEntry { id, customerId, objectKey, originalFilename, contentType, comment? @db.Text,
     createdAt, updatedAt }` — `reaction Reaction?`.
   - `Reaction { id, inbodyEntryId @unique, emoji, createdAt }` (one per entry).
3. **Cascades:** `onDelete: Cascade` on Group→Customer, Customer→InbodyEntry, InbodyEntry→Reaction,
   Trainer→Group/Customer. (MinIO object cleanup is done in domain code, not here — rule 11.)
4. `prisma migrate dev --name init`; commit the generated migration.
5. `prisma/seed.ts`: one trainer (`coach@demo.test` / known password), one group, one customer
   (name + password), one InbodyEntry (no object needed, or a placeholder objectKey). Wire `prisma.seed`
   in `package.json` (coordinate: package.json is frozen — request the field be added in 0.2/1.3).
