# lib helpers: prisma, password, auth/jose, s3/minio, heic, slug

> Lane: BE. Owns `src/server/data/**`, `src/server/auth/**`, `src/server/lib/{password,s3,heic,slug}.ts`.
> Part of the Phase-1 **freeze** — feature lanes import these, never edit them (rule 17).

## Context
Provide the shared server utilities every route handler depends on. Advances all later phases.

**Required reading:** [`CLAUDE.md`](../../CLAUDE.md) · [`architecture.md`](../architecture.md) §2,§4 ·
[`mvp-decisions.md`](../mvp-decisions.md) · [`task-breakdown.md`](../task-breakdown.md) #1.3.

## Goal & non-goals
- **Goal:** prisma singleton, bcrypt password, jose session sign/verify + getters, MinIO client +
  put/get/delete + ensure-bucket, HEIC→JPEG, slug + name normalization helpers.
- **Non-goals:** No route handlers, no domain business logic (that's Phases 2–5).

## Files I own
- `src/server/data/prisma.ts` — PrismaClient singleton (guard against hot-reload duplication).
- `src/server/lib/password.ts` — `hashPassword`, `verifyPassword` (bcryptjs, cost ≥ 10).
- `src/server/auth/session.ts` — `signSession(payload)`, `verifySession(token)` (jose, HS256, env
  secret, exp); `getTrainerSession()` / `getCustomerSession()` reading cookies; cookie name constants
  `TRAINER_COOKIE` / `CUSTOMER_COOKIE`; `setSessionCookie` / `clearSessionCookie` helpers.
- `src/server/lib/s3.ts` — S3 client (`forcePathStyle: true`, endpoint+creds from env);
  `putObject(key, body, contentType)`, `getObjectStream(key)`, `deleteObject(key)`, `ensureBucket()`.
- `src/server/lib/heic.ts` — `isHeic(buffer/contentType/filename)`, `heicToJpeg(buffer): Promise<Buffer>`.
- `src/server/lib/slug.ts` — `slugify(name)`, `uniqueSlug(base, existsFn)` (random suffix fallback for
  empty/non-ASCII); `normalizeName(name)` = `name.trim().toLowerCase()`.

## Approach
1. Keep each helper framework-agnostic where possible. `session.ts` may read `cookies()` only in the
   getter helpers used by handlers — the sign/verify core takes plain strings (testable, Edge-safe).
2. **jose** for JWT so the same verify works in Edge middleware. **bcrypt stays out of Edge** (rule 10).
3. MinIO: `ensureBucket()` is best-effort (HeadBucket→CreateBucket) so a fresh `docker compose up`
   never 500s.
4. HEIC: wrap conversion in try/catch; throw a typed error the handler maps to 400.
