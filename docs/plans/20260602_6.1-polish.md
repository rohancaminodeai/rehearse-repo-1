# Polish: empty/error states, toasts, revalidation

> Lane: FE. Sequential-ish (runs after the feature phases). Touches existing pages/components only.

## Context
Make every screen demo-safe: consistent empty/error states, toasts on mutations, refresh after writes.
Advances NFR UX + rule 16.

**Required reading:** [`CLAUDE.md`](../../CLAUDE.md) · [`task-breakdown.md`](../task-breakdown.md) #6.1.

## Goal & non-goals
- **Goal:** audit every screen for an **empty state** and an **error state**; success/error **toasts**;
  `router.refresh()` after every mutation; consistent loading/pending affordances.
- **Non-goals:** No new features, no redesign, no animation polish beyond shadcn defaults.

## Files I own
- Existing FE pages/components from Phases 2–5 (no new contract/frozen files).

## Approach
1. Walk each screen: trainer login/signup, dashboard (no groups / no customers / no entries),
   customer portal (login error / no entries), InBody module (upload error, delete confirm).
2. Add a shared toast usage pattern (shadcn `Toast`). Ensure failed `fetch` surfaces `ApiError.message`.
3. Confirm `router.refresh()` (or revalidation) after create/patch/delete/upload/reaction.
