# Contracts: Zod schemas + shared TS types (the parallelization seam)

> Lane: BE. Owns `src/server/api/_schemas/**` + `src/shared/types/**`. Part of the Phase-1 **freeze** —
> these define the FE↔BE agreement and must not change after Phase 1 (CLAUDE.md rule 17). Runs in
> parallel with 1.1 (disjoint paths).

## Context
Freeze the request/response contract for **every** endpoint so the FE, BE, and TEST lanes can build
independently. This is the single most important enabler of safe parallel work.

**Required reading:** [`CLAUDE.md`](../../CLAUDE.md) · [`requirements.md`](../requirements.md) §4 ·
[`architecture.md`](../architecture.md) §6 · [`task-breakdown.md`](../task-breakdown.md) #1.2.

## Goal & non-goals
- **Goal:** Zod schemas + inferred TS types for all endpoints; one import surface for FE + BE.
- **Non-goals:** No handler logic, no DB calls — schemas/types only.

## Files I own
- `src/server/api/_schemas/{auth,groups,customers,inbody,reaction}.ts`
- `src/shared/types/{auth,groups,customers,inbody,reaction,index}.ts`
- `src/server/lib/errors.ts` *(shared error shapes — declare here so BE/FE agree; if 1.3 also needs it,
  1.3 imports it. Owned here to avoid a later collision.)*

## Approach
1. **Auth schemas:** `trainerSignup { email, password(min8), name }`, `trainerLogin { email, password }`,
   `customerLogin { name, password }` (slug comes from the route path, not the body).
2. **Groups:** `createGroup { name, note? }`.
3. **Customers:** `createCustomer { groupId, name, password(min4) }`, `patchCustomer { name?,
   password?, groupId? }`.
4. **Inbody:** `uploadMeta { customerId, comment? }` (file handled as multipart, validated in handler),
   `patchComment { comment }`.
5. **Reaction:** `setReaction { emoji }` (constrain to a small allowlist of emoji strings).
6. **Response types** in `src/shared/types`: `TrainerDTO`, `GroupDTO`, `CustomerDTO` (no passwordHash),
   `InbodyEntryDTO` (id, originalFilename, contentType, comment, createdAt, reaction?), `ReactionDTO`,
   and a uniform `ApiError { code, message }`. Infer input types from Zod via `z.infer`.
7. Barrel-export from `src/shared/types/index.ts`.
