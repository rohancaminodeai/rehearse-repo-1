- **Non-goals:** No charts/metrics, no AI report (deferred placeholders only if needed), no reaction UI

## Files I own

- `src/components/inbody-module.tsx` — upload drop-zone, grid of entry cards, preview Dialog, actions.

## Approach
1. Upload via `multipart/form-data` POST to `/api/inbody`; show pending + error states; `router.refresh()`
   after. Accept jpeg/png/heic; client-side size hint (server is the gate).
2. Entry image `src` = the **proxy route** `/api/inbody/[id]/file` (never a public URL). Preview modal
   shows the full image + comment + download (`?download=1`).
3. Edit comment = inline/Dialog text field → `PATCH /api/inbody/[id]`; plain-text render (rule 16).
4. Delete = confirm Dialog → `DELETE`; optimistic-free, just refresh.
5. **Empty state**: no entries → drop-zone prompt (rule 16).
