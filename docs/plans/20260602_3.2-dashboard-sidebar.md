# Trainer dashboard shell: sidebar + group/customer modals

> Lane: FE. Owns `src/app/(trainer)/dashboard/{layout,page}.tsx`,
> `src/components/{sidebar,groups,customers}/**`.
> Parallel with 3.1 (BE) and 3.3 (TEST); codes against frozen contracts.

## Context
The persistent-sidebar workspace from the mockup: collapsible groups → customers, add/edit/delete via
modals. Advances FR-6…FR-10, T2–T4 and the UX described by the user.

**Required reading:** [`CLAUDE.md`](../../CLAUDE.md) · [`requirements.md`](../requirements.md) §workspace ·
[`architecture.md`](../architecture.md) §folders · [`task-breakdown.md`](../task-breakdown.md) #3.2.

## Goal & non-goals
- **Goal:** `dashboard/layout.tsx` (navy sidebar + center canvas); `sidebar.tsx` (brand, UI-only
  search, collapsible group list each toggling its customers, click loads customer); add-group /
  add-customer / edit-customer / delete modals; **empty states**; per-customer **portal link** display.
- **Non-goals:** No InBody module yet (Phase 4 fills the center for a selected customer), no search backend.

## Files I own
- `src/app/(trainer)/dashboard/layout.tsx` — sidebar + `{children}`; reads session-scoped groups.
- `src/app/(trainer)/dashboard/page.tsx` — default/empty center ("select a customer" / "create a group").
- `src/components/sidebar/**` — `Sidebar`, `GroupItem` (collapsible), `CustomerItem` (avatar-initial chip).
- `src/components/groups/**` — `AddGroupModal`.
- `src/components/customers/**` — `AddCustomerModal` (group, name, password), `EditCustomerModal`,
  `DeleteCustomerDialog`, portal-link copy field.

## Approach
1. Fetch groups+customers from `GET /api/groups`; render collapsible tree. shadcn `Dialog` for modals,
   `DropdownMenu` for row actions. Emerald accent, rounded cards, Korean copy from the mockup.
2. After any mutation, `router.refresh()` to revalidate (rule 16). Show toast on success/error.
3. **Empty states**: no groups → CTA to create; group with no customers → hint; (rule 16).
4. Portal link = `/portal/[trainerSlug]/login` shown per customer with copy-to-clipboard.
