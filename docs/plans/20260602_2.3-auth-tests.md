## Approach — cases
1. **Trainer signup**: success sets cookie; **duplicate email → 409**; weak password → 400.
2. **Slug**: two trainers, similar names → distinct unique slugs; non-ASCII name → random fallback slug.
3. **Trainer login**: wrong password & unknown email both return the **same generic error** (no field leak).
4. **Customer login**: scoped by slug; **normalized name** match (mixed case / surrounding spaces);
   right name+password under trainer A must not authenticate under trainer B's slug.
5. **Logout**: clears both cookies; idempotent.
6. **Middleware guards**: logged-out `/dashboard` → `/login`; logged-out `/portal/[slug]/dashboard` →
   `/portal/[slug]/login`; tampered/expired JWT → redirect (not 500).
