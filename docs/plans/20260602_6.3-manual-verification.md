## Steps
1. `cp .env.example .env`; `docker compose up -d` → Postgres + MinIO healthy (console :9001); bucket exists.
2. `npx prisma migrate dev && npx prisma db seed`; `npm run dev`.
3. **Trainer**: signup → login → create group → add customer (set password) → open InBody module →
   upload an image (appears → preview modal → download → edit comment → delete) → confirm object
   appears/disappears in MinIO console. **Upload a real `.heic`** → preview renders (converted), not blank.
4. **Customer**: open `/portal/[slug]/login` → log in with name + password → dashboard → preview/
   download → add/change emoji reaction → reload (persists) → trainer view shows the reaction.
5. **Access control**: logged-out `/dashboard` and `/portal/[slug]/dashboard` redirect to the correct
   login; a customer **cannot** fetch another customer's `/api/inbody/[id]/file` (404).
